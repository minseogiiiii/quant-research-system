# Q29.2-F/G candidate gates

F: durable route transitions recorded and fsynced before state publication; hash-chain verification and torn-tail identification. A failed ledger latches quarantine. A single polling writer decouples observer IPC from HTTP clients. The persistent SSE endpoint uses bounded connection/stream slots and a 120-second stream rotation. It emits full snapshots, not a lossless event feed, and terminates with resync_required on a changed generation or unavailable state. No cross-generation replay. Generation cursor is an epoch token, not a per-event offset.

G: two managed independent observers. A dead, unresponsive or persistently non-ready source is retired, with bounded exponential retry and a unique archive per attempt. No automatic failback while current source remains valid. Exact matching raw L2 hashes permit diagnostic Decimal top-ten comparison; mismatched hashes are NOT_COMPARABLE, not proof of divergence or parity. A comparable divergence quarantines both. No exchange-signed common checkpoint or gapless history is claimed. Public pilot requires explicit CLI opt-in and is limited to 180 seconds. CI uses only synthetic fixtures. No 30-minute or five-hour certification; no host redundancy or gateway supervision certification.

Remaining gates: full regressions, more fault and load cases (including slow clients, process restart during journal commit, disk failure and deadline contention), measured comparable checkpoint coverage on actual feed, independent archive replay across recovered epochs, 180s then 30m live and separate five-hour continuity/resilience acceptance.
