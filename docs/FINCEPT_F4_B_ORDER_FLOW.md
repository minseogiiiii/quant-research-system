# F4-B observed order flow candidate
Historical single admitted archive epoch only. Public market_trades updates are grouped by receiver-time and absolute price bucket; maker SELL means inferred aggressor buy, maker BUY means inferred aggressor sell. Coinbase Advanced Trade channel specification and July 30 2025 changelog document trade side as maker side: https://docs.cdp.coinbase.com/coinbase-app/introduction/changelog . Snapshot trades are excluded, identical later update repeats are excluded, conflicting IDs fail closed. CVD starts at request start and is observed signed base volume, not venue-wide volume or an alpha signal. Empty buckets mean no observed unique updates, not proof of no trades or a source gap. Reuse v35 ingress and independent replay; current aggregate tests synthetic. Independent real archive bucket parity, OFI/markout labels, execution analysis, browser UI, and live admission remain separate gates. NO CONFIRMED EXECUTABLE ALPHA.
