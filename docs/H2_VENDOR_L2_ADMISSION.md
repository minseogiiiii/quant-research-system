# H2 local vendor L2 adapter
Tardis CSV schema: https://docs.tardis.dev/downloadable-csv-files/data-types ; Coinbase Exchange: https://docs.tardis.dev/historical-data-details/coinbase ; license: https://docs.tardis.dev/legal/terms-of-service section 23. No remote download, API key or redistribution. Use only data you are authorized to process locally. Explicit gzip SHA-256, day, symbol, row order, microsecond vendor receive and venue times. Initial pre-snapshot rows counted/skipped. False->true resets book and separates epoch. Snapshot must share one receive timestamp (strict candidate profile, reject unsupported rather than invent continuity). Equal receiver clocks retain row order; inferred groups are not native packets. Bounded batch Parquet and independent Decimal final book per epoch. No native sequence/monotonic clock/gap or native Coinbase Advanced equivalence. Dataset stays research-ineligible until real vendor-format validation and a source-specific research policy are complete. No raw or derived vendor data uploaded to CI.
