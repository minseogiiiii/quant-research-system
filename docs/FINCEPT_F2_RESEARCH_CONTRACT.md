# F2 qualification boundary

Do not merge or expose vendor-linked analytics as an application until combined-work license treatment is decided. These tests run isolated from capture and use deterministic synthetic inputs. Existing Sharpe uses ddof=0 (population); upstream Fincept uses ddof=1 (sample), so both are named explicitly and neither silently replaces the other. Require finite complete returns on an explicit regular grid before upstream PBO; its missing-value coercion is not accepted. Event-time forward splits require actual feature and label availability and embargo, not a fixed bar count. Callers must independently validate that labels/features never span invalid source epochs; this split helper does not prove provenance. PSR/DSR formula witness and PBO smoke test do not validate trading profitability or full statistical robustness. No actual strategy or OOS acceptance.
