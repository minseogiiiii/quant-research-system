# H6 runner
Freeze actual source code digest, complete candidate inventory, costs and H4 catalog before replay. Fixed recovery policy except predeclared hold horizon 5/10/30/60s. One product per experiment, up to eight variants, sixteen whole native development epochs. Re-run F6/F7 event-driven simulation from cash for every session, require complete regular marks and final flat cash; compare compounded returns to cash ledger. Incomplete/failed sessions retained, never silently removed. Segmented return hashes are NOT H5 continuous matrices. No holdout accepted, no selection or OOS approval. This runner is local, bounded, and offline. Actual fold model fitting, new independent data, strategy selection, approval and deployment remain separate gates.
