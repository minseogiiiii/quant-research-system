# F3-D session-bound Funnest candle candidate
On the F3 branch only, checked engine caches one completed candle bundle per product at exact quote publication. The existing pair transport carries it; no second HTTP/SSE source. All bundle fields are bound to the admitted quote version and source session, and invalidation clears the cache. The UI blocks absent or malformed bundles, remounts chart on source epoch change, and rejects changes to retained candle history. Existing v36 observed trade candle logic reused, not an independently reconciled trade-derived candle certificate. Independent real-source archive candle parity, payload performance stress, live browser failover, and audit before merging into B5 infrastructure remain mandatory. No live order or alpha approval.
