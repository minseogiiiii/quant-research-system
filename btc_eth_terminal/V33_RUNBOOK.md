# v33 professional BTC/ETH Quant Research Terminal

## Launch locally

Extract the full v33 release ZIP into a new folder. Use Python >= 3.11 and run:

```bash
python backend/bridge.py
```

Open `http://127.0.0.1:8765/research` in a browser. This is **the actual v33 React/Funnest professional workspace**, compiled from the exact source in `frontend/src/` and pinned to the reviewed v33 JS/CSS manifest. It does not require npm installation at runtime. For the older dependency-free research view, open `http://127.0.0.1:8765/terminal`.

Use BTC-USD / ETH-USD buttons, select a frozen receiver-asof diagnostic, or choose Play / Pause / Step / Latest. The selected time simultaneously bounds the real chart, L1 quote and sampled tape. Historical candles are displayed only after their receiver-time interval closes. No order buttons, API credentials, live trade execution, account balances or fabricated returns are provided.

The L1 book shows one actual recorded best bid/ask level, rather than a fake multi-level ladder. Liquidity Recovery is an explicitly blocked research capability, not a computed alpha curve.

## Actual UI proof

The screenshot files `reports/v33_desktop_actual.png` and `reports/v33_mobile_actual.png` were generated by executing the production Vite bundle in headless Chromium with actual HTTP responses from the Python API. ## Validation

```bash
python -m unittest discover -s tests -q
python -m unittest discover -s tests -p 'test_v33*.py' -q
python -m compileall -q backend scripts tests
node --check frontend/standalone/app.js
tsc -p frontend/tsconfig.contract.json
python scripts/v33_browser_contract.py
```

A fresh `npm ci --ignore-scripts --no-audit --no-fund && npm run build` may produce different browser asset hashes. Do **not** overwrite the frozen `frontend/dist/` with a new build without a new integrity manifest, code pin and complete release revalidation. The recorded production build came from GitHub Actions run 43812306439.
